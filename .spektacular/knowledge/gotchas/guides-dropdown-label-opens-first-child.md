# The Guides dropdown label opens its first child

In `src/components/Nav.astro`, a dropdown's label links to its first child. Whatever is listed first under **Guides** is also where clicking "Guides" goes.

**How to apply:** when adding or reordering pages in a dropdown, put the page the label should open first. Changing the first item changes where the label goes.
