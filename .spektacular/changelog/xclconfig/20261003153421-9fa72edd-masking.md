# Documentation for masking sensitive values

The site now explains how xcl masks sensitive values. The events guide describes what event data shows for a sensitive value, how to choose a different masker and how to turn masking off, and a new State masking guide shows how to encrypt the secrets xcl keeps in state, why the state masker must be reversible, the warning shown while state is unencrypted, and the built-in maskers.

> Derived from project xcl (xcl-website), spec/plan 20261003153421-9fa72edd-masking. See the project-level record for the full feature.

## What changed in this repo

- `src/pages/events.mdx`: new section "Sensitive values in event data".
- `src/pages/state-masking.mdx`: new State masking page.
- `src/components/Nav.astro`: "State masking" added to Guides.
- `src/pages/sensitive-values.mdx`: links to the new page.
- `README.md`: the page added to the Pages table.

## Why

The library gained pluggable masking for state and events; the site is where developers learn to configure it, so it needed the same coverage as the library's own documentation.
