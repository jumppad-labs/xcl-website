# Documentation site moved to the query API v2 surface

Every page on the site now shows the lookup surface the library actually has. The landing page's
headline example — the first code a visitor reads — and the feature description beside it both use
the new API, as do all three example pages. No page mentions the superseded query helper any more.

> Derived from project xclconfig (file), spec/plan 20260921093100-query-api-v2. See the project-level
> record for the full feature.

## What changed in this repo

**`src/pages/index.mdx`** — the headline Go example moves from `xcl.NewQuerier[PostgreSQL](c).FindResource(...)`
to `xcl.Find[PostgreSQL](c, "resource.postgres.main")`. The snippet was also repaired while being
rewritten: it never checked the error from `Apply`, and the value it fetched was never used, so it
could not have compiled if a reader had tried it. The `🔎 Typed queries` feature card, which named
`NewQuerier[T]` explicitly, now describes `Find[T]` and `FindByType[T]`.

**`src/pages/examples/application-config.mdx`** — the by-address lookup moves to `xcl.Find[T](c, addr)`.

**`src/pages/examples/configuration-only.mdx`** — the list-by-type lookup moves to
`xcl.FindByType[T](c, "resource", "deployment")`, and the prose naming the old helper is rewritten.

**`src/pages/examples/plugins.mdx`** — the list-by-type lookup moves likewise, and two lowercase
prose mentions of "querier" are rewritten. Those two were the reason the check for this work had to
ignore case: a search for the capitalised constructor would have passed while leaving them in place.

**`README.md`** — the page table listed three pages; the site has four. Corrected while the file was
open, since it is the table a contributor consults to find the page they need to update.

All samples are written in the portable function form — `xcl.Find[T](c, addr)` rather than the method
form — because the method spelling requires a newer Go than the library supports, and a reader must
be able to copy a sample and have it compile.

Verified by building the site: all four pages render, and the built HTML contains the new surface
with zero occurrences of the old name.

## Why

The site is where someone meets this library for the first time, and the landing page's example is
the first code they read. Showing a helper that no longer exists would have made the first thing a
visitor tried fail to compile. Samples on the site are maintained by hand against the library's
`example/` directory — the policy recorded in this repo's README — so they move when that code moves.

Note that site samples are **not** compile-checked; that was considered and dropped during planning.
They are written in the portable form by convention, and the guard that runs is a case-insensitive
search for the superseded name.
