# Configuration-text guide: dependency lists

The configuration-text guide now explains how a written `depends_on` list appears in configuration text. A list you wrote is shown exactly as you wrote it, and none appears when you wrote none. Dependencies xcl works out from references are never added to it, though they still order creation and destruction.

> Derived from project xcl (xclconfig), spec/plan 20261003153421-c283547c-user-depends-on. See the project-level record for the full feature.

## What changed in this repo

- `src/pages/configuration-text.mdx`: a new "Dependency lists" section, placed before "Showing references as written". It has an example configuration and the text produced for it, and notes that live and saved text match.

## Why

The library now keeps a written `depends_on` list as written and shows it in configuration text. The guide documents that behaviour for readers of the site.
